## __HOW TO USE__

1. Open the venv with python

2. Run the main.py

3. Use the gui to enable 1 or more of the options, Blink, Mouth or Slam mode (see note to use)

###### Note:
__The Slam mode__ is only there to disable or enable the spacebar. Spacebar is also switched to press w instead of space for it to not loop back on itself. If you want to use the slam mode you need a magnetic keyboard and set the trigger sensitivity on the keyboard to the highest value on the spacebar key. I used the keyboard __ATTACK SHARK X68HE__
